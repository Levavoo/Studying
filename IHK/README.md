# IHK — zuerst konkrete Schwächen
[AP1-D01](AP1/Abgaben/AP1-D01.md) und [AP2-D01](AP2/Abgaben/AP2-D01.md) nutzen vorhandene eigene Prüfungsversuche. Keine komplette weitere Prüfung.
Der Mentor trennt: Fachwissen, Anwendung, Aufgabenverständnis, Vollständigkeit, Formulierung, Zeit.
Frühere Vermutungen (z. B. Normalisierung, Definitionen) sind keine bestätigte Diagnose dieses Probelaufs.

## Ablauf
1. Je Teil eine konkrete schwierige Antwort bis 16.10. dokumentieren.
2. Mentor prüft die eingereichten Diagnosen am 19.10. und ergänzt U01; maximal drei Schwächen insgesamt.
3. Je Teil 1–2 kleine Aufgaben bearbeiten, danach ohne Vorlage wiederholen.
4. IHK-Check 23.10., 15:10–15:30.
Eigene Antwort zuerst. Hilfen ehrlich angeben. Mentor-Musterlösungen sind keine offiziellen IHK-Lösungen; keine behaupteten offiziellen Punkte ohne Bewertungsgrundlage.
In die Papier-Kurzreferenz nur Fehlererkenntnis und präzises Antwortmuster übernehmen.
