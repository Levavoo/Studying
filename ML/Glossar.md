# Gemeinsames Glossar
| EN | DE | Bedeutung / Beispiel |
|---|---|---|
| observation | die Beobachtung | Eine gemessene Einheit, hier ein Haushalt pro Messtag. |
| feature | das Merkmal | Eine Eigenschaft einer Beobachtung, z. B. Verbrauch. |
| DataFrame | die Datentabelle | Zweidimensionale pandas-Struktur mit benannten Spalten. |
| missing value | der fehlende Wert | Wert unbekannt; nicht automatisch 0. |
| duplicate | das Duplikat | Wiederholter Datensatz; fachlichen Schlüssel beachten. |
| outlier | der Ausreißer | Auffälliger Wert; zunächst prüfen, nicht automatisch löschen. |
| data type | der Datentyp | Repräsentation wie Zahl oder Zeichenkette. |
| mean | der arithmetische Mittelwert | Summe der Werte geteilt durch ihre Anzahl. |
| median | der Median | Mittlerer Wert der sortierten Daten; bei gerader Anzahl Mittel der zwei mittleren Werte. |
| raw data | die Rohdaten | Unveränderte Ausgangsdaten für nachvollziehbare Verarbeitung. |
